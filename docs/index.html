// Project breakdown

7 Phases

Phase 01
Foundation — VirtualBox + GitHub
Set up VirtualBox for running multiple VMs. Created GitHub repository for version-controlled documentation. Downloaded Ubuntu Server and AlmaLinux ISOs.
VirtualBoxGitGitHubSSH keys
Phase 02
VyOS Router + VLAN Segmentation
Deployed enterprise VyOS router. Created 3 VLANs separating IT, HR and Finance departments. Configured NAT, inter-VLAN routing, and firewall rules blocking HR from Finance.
VyOSVLANsNATFirewallSubnetting
Phase 03
FreeIPA — Identity Management (Active Directory equivalent)
Deployed AlmaLinux 9 VM with FreeIPA — a full LDAP + Kerberos + DNS stack. Created department users and groups. Single sign-on across the entire lab infrastructure.
FreeIPALDAPKerberosDNSAlmaLinux
Phase 04
Samba File Server with Department Permissions
Configured Samba with 3 department shares. Group-based ACLs ensure each user can only access their own department folder. Verified cross-department access is denied.
SambaFile permissionsACLLinux groups
Phase 05
ELK Stack — Centralized Logging (SIEM)
Deployed Elasticsearch, Logstash and Kibana on a dedicated VM. Installed Filebeat on all servers to ship logs. Kibana dashboard shows real-time events across the entire infrastructure.
ElasticsearchKibanaLogstashFilebeatSIEM
Phase 06
WireGuard VPN Gateway
Deployed WireGuard VPN on the Samba VM. Generated server and client key pairs. Remote clients connect through encrypted tunnel and get full access to the internal 192.168.10.0/24 network.
WireGuardVPNEncryptionKey pairsiptables
Phase 07
Flask Helpdesk Web Application
Built a Python/Flask web app that ties the entire lab together. Real-time server monitoring by pinging all VMs, full IT ticket system with priorities and assignments, and live log feed from the ELK Elasticsearch API.
PythonFlaskSQLiteREST APIHTML/CSS
